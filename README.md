## 🌐 1-Minute Free Deployment Guide

### A. Deploy to GitHub Pages (Recommended)
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Hamsa B K engineering portfolio"
   ```
2. Create a repository named `portfolio` on GitHub under your account (`github.com/HamsaBK14/portfolio`).
3. Push your code:
   ```bash
   git remote add origin https://github.com/HamsaBK14/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, go to **Settings > Pages**, select **Branch: main** and **/ (root)**, then click **Save**.
5. Your portfolio will be live at: `https://hamsabk14.github.io/portfolio/`!

### B. Deploy to Vercel (Instant 1-Click)
1. Run:
   ```bash
   npx vercel
   ```
2. Follow the 2 prompts and your portfolio will be live on a fast global CDN with custom domains.
